# Hope Cuba

Webseite für "Hope Cuba e.V." nach der angehängten Masterprompt-Markdown-Datei erstellen.
Dabei die angehängten Bilddateien (Logos und Originalbilder aus dem Zip-Archiv sowie die Infografiken zur Situation auf Kuba) einbinden.
Eine separate Seite für die Satzung in DE, EN, ES erstellen (nach den angehängten Satzungsdokumenten). Später sollen dort auch noch die Geschäftsordnung und Finanz- und Abgabenordnung sein.
